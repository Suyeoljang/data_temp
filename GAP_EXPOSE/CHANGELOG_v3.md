### 추가 신호 18개 (모두 인과적, 요청 시점에 MEAS 불필요)

| 신호 | 개수 | 의미 |
|---|---|---|
| `DRIFT_<그룹>_<3/14>` | 14 | 레벨 drift. `log IDEAL = B[KEY] + D[그룹]`으로 추종한다. KEY가 마지막으로 진행된 이후 그룹(장비, 장비+layer, 제품+경로, 레티클, PR, 트랙, 장비+트랙)의 노광 수준 변화 |
| `K_LASTIDEAL` | 1 | log(KEY 직전 IDEAL / 현재 PROC) |
| `K_PROCCHG` | 1 | log(현재 PROC / KEY 직전 APC 원값) |
| `L3_21`, `L3_180` | 2 | log(DEV+ROUTE+EQ IDEAL EMA / 현재 PROC). BIAS_MIX8의 L3 블렌딩 항을 신호로 넣은 것 |

모든 신호는 RTOL로 정규화한다. 추가 신호는 ±5, 전체 신호는 ±8로 clip한다.

| 방식 | 노광량 변경 Lot | 구제 | 손실 | **순증** | 손실률 | CD≤1% 합격률 |

- 2026년 기준 임계값은 |β·보정량| ≥ 0.068 CD%였다(2025년 학습 구간에서 75%가 되는 값). 2026년 적용률은 79%다.

- 연구 단계에서 β는 16개월 모두 개선됐고, DUV 16대 중 14대가 개선됐다(나머지 2대는 ±2 Lot).

## β 배율

```
세그먼트 l 상태:  A_l = Σ w·s·u ,  B_l = Σ w·s²      w = 0.5^(경과일 / 60)
조회:            β_0 = 1,  β_l = (A_l + 20·β_{l-1}) / (B_l + 20),  β = clip(β_4, 0, 1.5)
계층:            장비 → 장비+ROUTE_DESC → DEV_ID+ROUTE → KEY(DEV_ID, PROC_EQ, ROUTE, RETICLE)
s = 엔진 원 보정량(CD% 단위, β·생략 적용 전), u = APC 원값 기준 CD 오차(CD%, ±5 clip)
```

- **의미:** β는 "그 세그먼트에서 보정량 1만큼 움직였을 때 실제 오차가 평균 얼마였는가"다. 1보다 크면 보정이 모자랐다는 뜻이다.
- **이력이 적을 때:** 이력이 적은 세그먼트는 상위 세그먼트의 β를 따른다. 이력이 전혀 없으면 β = 1이다.
- **갱신 대상:** 적용 장비 Lot 중 유효하고, 이력이 있고, FIX와 SC_IN_AI가 아닌 Lot이다. 평가 기준과 같다.
- **갱신 시점:** 일 배치다. 같은 날의 Lot은 전일까지의 β를 쓴다.
- **운영의 원 보정량:** `daily_update`가 배치 갱신 전 상태로 다시 계산한다. 요청 시점 상태와 같으므로 DB 스키마 변경이 필요 없다.

# v3.1.1 — 장기 GAP(GAP ≥ 30) 전용 운영 지원 (2026-10-15)

## 변경

- **`BETA_GAP_MIN` 추가 (기본 0):** β를 학습하는 Lot의 GAP 하한이다. 적용 범위(`GAP_THRESHOLD`)와 분리했다.
  - `GAP_THRESHOLD = 30`이어도 β는 같은 장비의 전 GAP Lot으로 추정한다.
  - 적용 임계값(`APPLY_RATIO`)은 적용 범위(GAP ≥ 30) Lot 기준으로 정한다.
- **버그 수정:** 이전 코드에서 `GAP_THRESHOLD > 0`이면 β 학습 범위가 서로 달랐다.
  - fit·replay는 GAP ≥ 30 Lot만으로 β를 학습했다.
  - daily_update는 전 GAP Lot으로 β를 갱신했다.
  - 이제 둘 다 `BETA_GAP_MIN` 기준을 따른다.

# v3.1.3 — 3구간 평가 (측정 오차 감안) (2026-10-19)

## 배경

- 공정 엔지니어 의견: CD 계측 자체에 오차가 있으므로 1% 근처의 판정은 확실하지 않다.
- 이전 판정은 1% 하나뿐이었다. 그래서 0.95% → 1.05% 같은 측정 오차 수준의 이동도 손실로 셌다.

## 3구간 판정 (`metrics.py`, `config.PASS_U` / `GRAY_U`)

| 구간 | CD 오차 | 점수 |
|---|---|---|
| 합격 | 1% 이하 (`PASS_U`) | 2 |
| 회색 | 1 ~ 2% (`GRAY_U`, 측정 오차 범위) | 1 |
| 불량 | 2% 초과 | 0 |

**보정 전후 이동 해석**
- 합격 → 불량: 확실한 손실
- 불량 → 합격: 확실한 구제
- 회색을 거치는 이동: 경미한 개선 / 경미한 악화

**3구간 점수** = Σ(보정 후 점수 − 보정 전 점수). 구제와 손실을 같은 무게로 대칭적으로 센다.

`GRAY_U`는 계측 Gauge R&R로 확정한다.

## 검증 (2025 학습 → 2026-01 ~ 07, DUV GAP ≥ 30, 38,639 Lot)

| 배율 / 적용 비율 | 3구간 점수 | 확실한 구제 / 손실 | 불량률 (2% 초과) |
|---|---|---|---|
| **1.0 / 0.75 (권장, 기본값)** | **+3,024** | 516 / 177 | 20.1 → 16.5% |
| 1.0 / 1.0 | +3,007 | 516 / 177 | 20.1 → 16.5% |
| 0.75 / 1.0 | +2,674 | 230 / 55 | |
| 1.5 / 1.0 | +2,439 | 1,146 / 717 | |
| 0.5 / 0.3 | +1,826 | 39 / 10 | 20.1 → 17.8% |

- 3구간 기준으로 다시 학습(±1%와 ±2% 동시, 또는 ±2%)해 봤지만, 2025 Q4 검증에서 현재 학습 방식(±1%)과 차이가 없었다. 학습 방식은 그대로 둔다.
- 1% 기준으로 손실로 셌던 Lot의 93%는 회색 구간으로 이동한 경우다.
